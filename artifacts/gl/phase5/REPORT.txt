3. WHAT THE FIXER CHANGED (all pixel-neutral: hashes identical)
  S2 / P6 (O7, major, FIXED): no per-frame or per-vertex path calls libc
    mem* at >= 64 B any more. zgl.h s31_wcopy / s31_wdiff: unrolled word
    loops with an opaque word (empty asm) so GCC cannot re-form a memcpy.
    Sites: glBegin's modelview-inverse cache (64 B memcpy + memcmp),
    glDrawElements vertex-cache hit/save (148-B GLVertex prefix, 4 call
    sites), glLoadMatrixf/glMultMatrixf (64 B, RV32 only - GLParam is 8 B
    on a 64-bit host), the S31Unpack copy per glTex[Sub]Image (68 B),
    t8_row's aligned client rows (per-frame lightmap rows), and the L8
    lightmap update no longer clears the 1 kB palette hash it never reads.
    Check: gl/tests/memchk-pie.sh (new; objdump of the RV32 library, the
    constant a2 before each mem*@plt): 16 -> 12 constant >= 64 calls, 0 of
    them per frame or per vertex (left: glXChoose*, s31_state_init,
    glRasterPos/glBitmap/glDrawPixels setup, the P8 palette scan (want=1),
    t8_compact, gl_M4_Inv for projective modelviews). A first, rolled
    version cost gl/bench geo11 +16.6% (the proxy's newlib memcpy is
    unrolled); unrolled by 8 it is back to the review tree except geo5
    +1.5% (0.6966 -> 0.7068: the 16-word compare has no early exit).
    Board check: count PIE bounces with swt-arm.sh (A/B list).
  P5 (minor, FIXED): s31_cap_index has a 64-slot direct-mapped memo,
    verified against caps[] (race-safe: a wrong slot costs a search).
  Trace: default -0.39% / -0.70%, tf0 -0.82% / -1.57%.

4. OPEN - OWNER DECISIONS (rejected for this round, with reasons)
  S1 GL_MAX_TEXTURE_SIZE 256 (major, NOT FIXED): stock TyrQuake 0.71 GL
    does not clamp to it (gl_textures.c GL_Upload32 rounds 320x24 up to
    512x32), so its status bar draws white. The 256 limit is built into
    the s/t fixed point and the fused fillers. Accepting >256 while
    advertising 256 is not allowed by the spec (INVALID_VALUE). Advertising
    512/1024 with a box-downsample at glTexImage2D is the cheap route, but
    QuakeSpasm scales its uploads to the advertised maximum, so it changes
    the QuakeSpasm trace (bar 2) and texture bytes: needs a re-capture and
    an owner call. Queued, not started (time box).
  S3 L8/P8 -> 565 conversion requantises untouched texels (minor):
    documented as a known deviation (s31_tex8.c header, README.s31). The
    exact fix (convert to the W32 layout) costs 4 B/texel: owner decision.
  P2 default-build bench over limits (major, OPEN): same-hash lines over
    +0.5% vs phase-4 final: pix6 glCopyTexSubImage2D +37.9%, pix2 blended
    glBitmap +13.1%, feat5 texobj +12.8%, texobj 640x400 +10.1% / 320x240
    +9.2% (the plan's +1% guard), feat4 +9.2%, feat2 +0.7%, feat3 +0.5%.
    Causes (review): P8 fetch rasteriser on tiny textures, the 8-bit
    statistics pass on every glCopyTexSubImage2D, the rounded SA/OMSA
    blend stage (+32%). Cheap leads, not done: P8/L8 only above a size
    threshold; a direct 565 store for 565-kind copies; a table-based
    rounded blend. The compat build -DS31GL_P4ARITH meets bar 2 (worst
    +0.422%, 0 hash changes; p5c/bench-s9-compat-vs-p4final.txt). Needs the
    owner's sign-off and new limits.txt values, or the leads.
  Trilinear bias (P1): LERPT adds 12/32 (G, B) and 11/32 (R) instead of
    rounding. It was tuned on three suite apps (fire, ipers, teapot) to
    clear the suite bar and is fragile by its own comment. Final tree vs
    phase-4 final: teapot f60 0.237 -> 0.237, fire f20 tolerant 0.319 ->
    0.309 but strict 0.684 -> 0.757 (rounded lerp was 0.270 / 0.624).
    The honest-precision arm is S31GL_FILT8=1 at +44% instructions.
  P4 per-level texel kinds: a texture's kind follows level 0, and
    QuakeSpasm's averaged mips exceed 256 colours, so ~117k of 127k world
    px/frame still sample 565. Measure with trace.py texmem before building.
  P5 next levers: trilinear world inner loop (zf8s_wx_tri 42.8%), the
    per-block LOD choice (6.7%), triangle setup (4.9%).

5. RUNTIME TOGGLES (environment, read at context creation) AND DEFAULTS
  S31GL_TEXFILTER   1   0 = nearest in level 0 for every filter, no mips
  S31GL_MIPMAPS     1   0 = levels > 0 not stored (bilinear from level 0)
  S31GL_TRILINEAR   1   0 = mip levels without the blend between them
  S31GL_PERSPCOLOR  1   0 = screen-affine Gouraud colour
  S31GL_FUSED       1   0 = general stage lists only (gate reference arm)
  S31GL_TEX8        1   0 = phase-4 565 storage, 2 = unpacked W32 reference
                        (default 0 in the -DS31GL_P4ARITH build)
  S31GL_FILT8       0   1 = 8-bit filters on 565 textures (+44%)
  S31GL_RAMTEXT     0   1 = hot fillers copied to RAM (board A/B)

  S31GL_SHMBUFS, S31GL_NOWAIT, S31GL_RENDER_SCALE, S31GL_TRACE (GLX /
