  12 over -> 7 over. What did it:
  a. s31_tex8.c t8_kind: a colour image of <= 256 colours all exact in
     565 is stored 565, not P8 (texobj's red/green/white). Nearest reads
     the same texels without the palette load; GLTexture.x565 sends it,
     filtered, through the 8-bit filters as P8 would (raster_sel.c
     UNIT_W8), so filtered pixels are unchanged too. Grey stays L8.
     (Without x565 the first cut failed glx_mtex page 3: 2.58% -> 3.99%.)
  b. gl_tex8_sub: glCopyTexSubImage2D over the whole of an RGB/RGBA
     texture's only level converts L8/P8 to 565 once; st565_rows stores
     the colour buffer's 565 values directly (no 8-bit row, no rounding
     pass; the expansion and T565 are inverse). pix6 was an L8 (black,
     no-pixels) texture re-scanned on every copy.
  c. zpipe.c zo_sa_omsa: one-alpha chunks (word test) use zf_btab's
     destination tables + a 256-B source table for that alpha
     (ZPipeX.satab); alpha 255 is a plain store; other chunks prepare the
     two factors once per pixel (MUL8K: (257 n + 32896) >> 16 = round(n /
     255), checked for every n <= 70000). zo_sa_one and the subtract
     pairs prepare the factor per pixel.
  d. zpipe_int.h div255r = (n + 128) * 257 >> 16 with 257 in an opaque
     register: 4 instructions instead of 5, same value (n <= 70000).
  Compat build (-DS31GL_P4ARITH): 0 of 74 hashes differ from phase-4
  final; worst geo5 +1.49% (geo5 is 0.7068 in the default build both at
  105effc and now - not a fix-2 change; the review's compat worst +0.42%
  was measured on an earlier tree).

2. GL_MAX_TEXTURE_SIZE 512 (owner decision, done)
  zgl.h TGL_TEX_MAX 512: get.c, texture.c (levels 0..9; 1024 and level 10
  GL_INVALID_VALUE; proxies answer 0 above 512 >> level), the s31_tex8.c
  row buffers (512 wide). The s/t fixed point keeps F + ws + hs <= 22: a
  512 x 512 texture has 4 fraction bits, so its bilinear weights move in
  16 steps instead of 32 (512 x 32 has 8, no loss). core_test: 512x2
  upload + draw (P8, both halves), proxy 512 yes / 1024 no / level 1 at
  512 no, level 10 invalid (core_test 286 -> 292 host, 284 -> 290 RV32).
